# Support

Kid-OS is pre-release community software. The project does not currently provide
a managed service, production SLA, emergency safeguarding response, legal
advice, or regulatory certification.

Use GitHub issues for reproducible bugs and scoped feature proposals. Include the
commit or version, environment, expected behavior, actual behavior, and a minimal
reproduction using synthetic data.

Never post real child, resident, staff, home, incident, credential, trace, log,
or database data in an issue. Report vulnerabilities privately as described in
[SECURITY.md](SECURITY.md).

Questions about operating a fork should include the relevant public
configuration and sanitized diagnostics. Maintainers cannot access or administer
downstream deployments.
